# Student Shop — интернет-магазин на Django

Учебный проект интернет-магазина, разработанный на Python с использованием Django.

## Реализованные функции

- Просмотр списка товаров с названиями, описаниями, ценами и фотографиями.
- Добавление новых товаров через форму Django ModelForm с возможностью загрузки изображения.
- Регистрация новых пользователей.
- Авторизация и выход из аккаунта.
- Перенаправление пользователя после входа.
- Добавление товаров в корзину для авторизованных пользователей.
- Просмотр корзины, изменение количества товаров и очистка корзины.

## Используемые технологии

- Python
- Django
- PostgreSQL
- HTML и CSS
- Git и GitHub

## Запуск проекта

1. Установить зависимости из файла `requirements.txt`.
2. Создать файл `.env` с необходимыми настройками Django и подключения к PostgreSQL.
3. Настроить базу данных.
4. Выполнить миграции.
5. Запустить сервер командой:

```bash
python manage.py runserver
```
