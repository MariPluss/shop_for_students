# Доработка учебного Django-магазина

Реализовано по `DZ(10).ipynb`: добавление товара через ModelForm (включая файл изображения), регистрация, вход, выход, редирект после входа, проверка авторизации при добавлении в корзину.

## Запуск
1. Откройте папку `shop_for_students` в VS Code.
2. Создайте новое виртуальное окружение и установите зависимости: `pip install -r requirements.txt`.
3. Подготовьте PostgreSQL и базу `student_shop`. Проверьте настройки `DATABASES` в `student_shop/settings.py` (пароль из учебного проекта замените своим).
4. `python manage.py migrate`
5. `python manage.py runserver`
6. Откройте http://127.0.0.1:8000/

## Примечания
- Исходная корзина общая для всех пользователей (в модели CartItem нет связи с User). Авторизация защищает добавление/просмотр/очистку, но **не разделяет корзины пользователей**. Для реального магазина нужна отдельная миграция.
- Страница добавления товаров доступна всем, как и сформулировано в задании. Для реального магазина потребуется ограничить права.
- Не используйте учебные DEBUG/SECRET_KEY/пароль базы данных в продакшене.
- Архив не включает старое виртуальное окружение: его лучше создавать заново на своей машине.
